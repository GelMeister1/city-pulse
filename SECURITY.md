# Security Policy

## Supported Versions

Only the latest release gets security fixes. City Pulse updates itself, so installed copies move to the newest version automatically.

| Version | Supported |
| ------- | --------- |
| Latest release | ✅ |
| Older releases | ❌ |

## Reporting a Vulnerability

Please don't report security problems in public issues.

Report them privately instead:
1. Open the **Security** tab of this repository.
2. Click **Report a vulnerability**.
3. Describe the problem, the steps to reproduce it, and the City Pulse and Windows versions you used.

What to expect:
- A first reply within 7 days.
- If the report is confirmed, a fixed release, published as soon as it's ready. Installed copies pick it up automatically. You'll be credited in the release notes unless you'd rather not be.
- If the report is declined, a short explanation of why.

City Pulse is a hobby project maintained by one person, so these are best-effort times.
